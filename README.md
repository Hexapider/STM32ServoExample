# STM32ServoExample
An example of servo control using STM32.

Two header files are written in C++.

To add a servo, go to the HXPServoConfig.h file and add an entry to SERVO_LIST following this format:

 X(servo name, timer, channel, min pulse, max pulse, max angle) \

The `main` file is generated by STM32CubeMX in C. Since I am using C++ for this implementation, I need to bridge the two languages.

In the initialization section of `main.c`, write:

Servo_Init();

And use it like this:

void Servo_write(name, angle);

void Servo_writeMicroseconds(name, us);
